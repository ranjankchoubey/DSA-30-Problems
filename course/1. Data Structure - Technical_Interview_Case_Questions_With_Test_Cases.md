**Data Structure Technical Interview Preparation**

30 Case-Based Questions With Test Cases, Topic-Wise

*How to read this document: each question is a business scenario with constraints, followed by exactly 3 test cases. For coding questions the test case is an input and its expected output.. Numeric answers were checked by running code.*

# **1\. Arrays & Strings**

**Q1. Fraud Pattern Detector (Subarray Sum Equals K)**

A payments company monitors a stream of account balance changes (credits are positive, debits are negative). The risk team wants to count how many contiguous segments of transactions have a net sum exactly equal to a target value k, because such segments match a known laundering pattern. The array can contain negative numbers, so a sliding window will not work. Write a function that returns the count in O(n) time. Explain why prefix sums with a hash map solve it, and what changes if you must also return the start and end indices of every segment.

Constraints: 1 \<= n \<= 200,000; \-1000 \<= nums\[i\] \<= 1000; \-10^7 \<= k \<= 10^7.

| Test | Input / Scenario | Expected Output |
| :---- | :---- | :---- |
| **TC 1** | nums \= \[1, 1, 1\], k \= 2 | 2 |
| **TC 2** | nums \= \[1, 2, 3, \-3, 3\], k \= 3 | 5 |
| **TC 3** | nums \= \[0, 0, 0\], k \= 0 | 6 |
